# Неделя 1, День 3 — функции, множественные возвраты, defer

**Время:** 60 минут
**Цель:** писать функции, возвращающие `(результат, error)`, и понимать, как работает `defer`.

Сегодня появляется главная идиома языка: **ошибка — это обычное возвращаемое значение**. Не исключение, не throw. С этого дня она будет в каждом файле до конца плана.

Go by Example, три короткие страницы:

Ключевое на сегодня:

- Функция возвращает несколько значений: `func f() (int, error)`. Ошибка — **всегда последняя**
- Если ошибка не `nil`, остальные значения считаются невалидными. Вызывающий проверяет ошибку первой строкой
- Результаты можно именовать: `func f() (n int, err error)`. Тогда работает «голый» `return` — но в длинных функциях так делать не стоит, читаемость падает
- `defer` откладывает вызов до выхода из функции — при любом исходе, включая панику
- Несколько `defer` выполняются в обратном порядке, стопкой
- **Аргументы отложенного вызова вычисляются сразу**, в момент `defer`, а не в момент выполнения

### Задача 1. Парсер списка чисел (≈25 мин)

Функция принимает строку вида `"12,45,7"` и возвращает срез чисел либо ошибку.

**Требования:**

| Вход | Ожидаемый результат |
|---|---|
| `"12,45,7"` | `[12 45 7]`, `nil` |
| `"12, 45 , 7"` | `[12 45 7]`, `nil` — пробелы вокруг чисел допустимы |
| `""` | `nil`, `nil` — пустой вход не ошибка |
| `"12,abc,7"` | `nil`, ошибка с указанием позиции и значения |
| `"12,,7"` | `nil`, ошибка |

- [ ] Создать `<ваше-имя>/week01/day03/parseints/main.go`:

```go
package main

import (
	"fmt"
	"strconv"
	"strings"
)

// parseInts разбирает строку вида "12,45,7" в срез чисел.
// Пробелы вокруг элементов игнорируются. Пустая строка даёт (nil, nil).
// При первом же нечисловом элементе возвращает (nil, ошибку).
func parseInts(s string) ([]int, error) {
	// ваш код
}

func main() {
	cases := []string{
		"12,45,7",
		"12, 45 , 7",
		"",
		"12,abc,7",
		"12,,7",
	}

	for _, c := range cases {
		nums, err := parseInts(c)
		if err != nil {
			fmt.Printf("%-15q → ошибка: %v\n", c, err)
			continue
		}
		fmt.Printf("%-15q → %v\n", c, nums)
	}
}
```

Что понадобится:

- `strings.Split(s, ",")` — разбить строку
- `strings.TrimSpace(part)` — убрать пробелы
- `strconv.Atoi(part)` — превратить в число; возвращает `(int, error)`
- `fmt.Errorf("элемент %d: %q не является числом", i, part)` — собрать осмысленную ошибку

**Проверка:**

```bash
go run ./<ваше-имя>/week01/day03/parseints
```

Все пять случаев отрабатывают согласно таблице. Ошибка должна называть **конкретную позицию и конкретное значение** — «неверный формат» бесполезно и вам, и будущему пользователю API.

```go
}
```

## Частые грабли третьего дня

**Игнорирование второго возвращаемого значения.** `n, _ := strconv.Atoi(part)` компилируется, при мусоре молча даёт `0` и создаёт баг, который найдётся через неделю в проде. Ошибку глотать можно только осознанно и с комментарием, зачем.

**`strconv.Atoi(" 12")` возвращает ошибку.** Пробел — не цифра. Именно поэтому `TrimSpace` в требованиях, и именно поэтому в таблице есть случай с пробелами.

**Возврат частичного результата вместе с ошибкой.** Если ошибка не `nil`, возвращайте `nil` в качестве среза. Половина разобранного списка вместе с ошибкой — приглашение вызывающему её проигнорировать.

**`defer` внутри цикла.** Откладывает до выхода из **функции**, а не из итерации. В цикле на десять тысяч элементов это десять тысяч накопленных вызовов и незакрытых ресурсов. Если нужно освободить ресурс на каждой итерации — выносите тело цикла в отдельную функцию.

**`defer track("x")` вместо `defer track("x")()`.** Без вторых скобок вы откладываете вызов `track`, который вернёт функцию и выбросит её. Замер не сработает, а `go vet` в этом случае промолчит.

**Затенение переменной через `:=`.** Внутри `if` или цикла `err := ...` создаёт **новую** переменную, а не переписывает внешнюю. Классический источник «ошибка есть, но снаружи её не видно».

## Если осталось время

Именованные результаты плюс `defer` дают приём, который вы встретите в чужом коде: отложенная функция может **изменить** возвращаемое значение.

```go
func parse(s string) (result []int, err error) {
	defer func() {
		if err != nil {
			err = fmt.Errorf("разбор %q: %w", s, err)
		}
	}()
	// ...
}
```

Сегодня достаточно понять механику: тело `defer` видит именованные результаты и может их переписать. Что означает `%w` — тема второй недели, пока просто запомните, что так оборачивают ошибки.
