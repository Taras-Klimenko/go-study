## 0–10 мин. Чтение

[Tour of Go](https://go.dev/tour) — пройти два раздела:

- [ ] **Packages, variables, and functions** — до конца
- [ ] **Flow control statements** — до конца

Упражнения внутри тура выполнять прямо в браузере, не переносить в репозиторий. Это разминка, а не работа.

На что обратить внимание по дороге:

- `var` работает везде, `:=` — **только внутри функций**
- Неинициализированная переменная получает нулевое значение: `0`, `""`, `false`, `nil`. Никакого `undefined`
- Преобразование типов только явное: `float64(i)`, а не `i` там, где ждут `float64`
- `for` — единственный цикл в языке. `while` нет, его роль играет `for условие { }`
- `switch` не проваливается в следующий case, `break` писать не нужно
- `switch` без выражения — это замена лестнице `if / else if`

### Задача 1. FizzBuzz (≈10 мин)

Классика, но с важной оговоркой: **логика живёт в отдельной функции, возвращающей строку**, а не печатает напрямую. На третьей неделе вы вернётесь к этому коду и покроете его тестами — печать в консоль тестировать неудобно.

- [ ] Создать `<ваше-имя>/week01/day02/fizzbuzz/main.go`:

```go
package main

import "fmt"

// fizzBuzz возвращает "Fizz" для кратных 3, "Buzz" для кратных 5,
// "FizzBuzz" для кратных 15 и само число строкой в остальных случаях.
func fizzBuzz(n int) string {
	// ваш код
}

func main() {
	for i := 1; i <= 100; i++ {
		fmt.Println(fizzBuzz(i))
	}
}
```

- [ ] Реализовать `fizzBuzz` через `switch` без выражения (`switch { case ... }`) — это идиоматичнее лестницы `if / else if`
- [ ] Число в строку превращает `strconv.Itoa(n)`

**Проверка:**

```bash
go run ./<ваше-имя>/week01/day02/fizzbuzz
```

Строка 15 — `FizzBuzz`, строка 20 — `Buzz`, строка 98 — `98`.

### Задача 2. Конвертер температур с флагами (≈20 мин)

Программа принимает значение и единицу измерения, печатает результат в другой шкале.

```bash
go run ./<ваше-имя>/week01/day02/tempconv -value 100 -unit c
# 100.0°C = 212.0°F

go run ./<ваше-имя>/week01/day02/tempconv -value 32 -unit f
# 32.0°F = 0.0°C
```

- [ ] Создать `<ваше-имя>/week01/day02/tempconv/main.go`:

```go

	"flag"
	"fmt"
	"os"
	"strings"
)

func cToF(c float64) float64 {
	// ваш код
}

func fToC(f float64) float64 {
	// ваш код
}

	value := flag.Float64("value", 0, "значение температуры")
	unit := flag.String("unit", "c", "исходная шкала: c или f")
	flag.Parse()

	// flag.Float64 и flag.String возвращают УКАЗАТЕЛИ.
	// Разыменовывать через *value и *unit.

	switch strings.ToLower(*unit) {
	// ваш код: две ветки и default
	// в default — сообщение об ошибке и os.Exit(1)
	}
}
```

- [ ] Формулы: `F = C×9/5 + 32`, `C = (F−32)×5/9`
- [ ] Вывод форматировать через `fmt.Printf` с `%.1f`

**Проверка:**

- [ ] `-value 100 -unit c` даёт 212.0°F
- [ ] `-value 32 -unit f` даёт 0.0°C
- [ ] `-value -40 -unit c` даёт −40.0°F (точка, где шкалы совпадают — хорошая проверка формулы)
- [ ] `-unit k` печатает ошибку и завершается с кодом 1
- [ ] `-h` показывает справку по флагам — её генерирует пакет `flag` сам

## Частые грабли второго дня

**«declared and not used».** Объявленная и неиспользованная переменная — это **ошибка компиляции**, а не предупреждение. То же с неиспользуемым импортом. После JavaScript это самое неожиданное свойство языка. Лечится удалением, а для временной заглушки — `_ = x`.

**`:=` на уровне пакета.** Вне функции работает только `var`. Ошибка выглядит как `syntax error: non-declaration statement outside function body`.

**Неявного преобразования типов нет.** `var i int = 5; var f float64 = i` не скомпилируется. Нужно `float64(i)`. В формуле конвертера всё должно быть `float64` — целочисленное деление `9/5` даст `1`.

**Забытый `flag.Parse()`.** Программа соберётся и запустится, но все флаги будут нулевыми. Симптом: что бы вы ни передали, на выходе `0.0`.

**Флаги возвращают указатели.** `flag.Float64` даёт `*float64`. Без `*` вы получите ошибку типов или напечатаете адрес.

**Порядок аргументов в `go run`.** Всё после пути к пакету уходит в программу: `go run ./path -value 100`. Флаги, поставленные перед путём, достанутся самому `go run`.
