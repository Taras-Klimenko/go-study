Что унести:

**Мапы**
- Создаются через `make(map[K]V)` или литерал. **Нулевое значение мапы — `nil`**
- Из `nil`-мапы читать можно, писать — паника
- Чтение отсутствующего ключа возвращает нулевое значение типа, а не ошибку
- Отличить «нет ключа» от «значение нулевое» позволяет форма `v, ok := m[k]`
- **Порядок обхода случаен намеренно.** Не «не определён», а именно рандомизирован при каждом запуске, чтобы на него нельзя было положиться

**Строки**
- Строка — неизменяемая последовательность **байт** в кодировке UTF-8
- `len(s)` считает байты. Для `"Привет"` это 12, а не 6
- `s[i]` возвращает **байт**, а не символ
- `for i, r := range s` даёт руну и её **байтовое смещение** — счётчик прыгает через 2 на кириллице
- Руна — это `int32`, кодовая точка Unicode

**А. Нулевая мапа.**

```go
var m map[string]int

```

Запустите, прочитайте текст паники целиком, потом закомментируйте последнюю строку.

**Б. Форма «запятая-ok».**

```go
scores := map[string]int{"таня": 0}
fmt.Println(scores["таня"], scores["петя"])       // и то и другое 0

v, ok := scores["таня"]
fmt.Println(v, ok)
v, ok = scores["петя"]
fmt.Println(v, ok)
```

Почему без `ok` эти два случая неразличимы — и когда это приведёт к багу.

**В. Байты против рун.**

```go
s := "Привет, Go!"
fmt.Println(len(s))                        // байты
fmt.Println(utf8.RuneCountInString(s))     // символы
fmt.Println(len([]rune(s)))                // то же самое другим способом
fmt.Printf("%c %c\n", s[0], s[8])          // посмотрите, что получится
```

Последняя строка — самое интересное. Объясните результат.

**Г. Обход строки.**

```go
for i, r := range "Привет" {
	fmt.Printf("%d: %c\n", i, r)
}
```

Обратите внимание на индексы. Это байтовые смещения, а не номера символов.

**Д. Случайный порядок обхода.**

```go
m := map[string]int{"а": 1, "б": 2, "в": 3, "г": 4, "д": 5}
for k := range m {
	fmt.Print(k, " ")
}
fmt.Println()
```

Запустите **три раза подряд**. Убедитесь, что порядок разный. Это сделано специально.

- Разбить на слова: `strings.FieldsFunc(s, func(r rune) bool { return !unicode.IsLetter(r) })`. Это лучше `strings.Fields`, который оставит точки приклеенными к словам

```go

for w, c := range counts {
	pairs = append(pairs, wordCount{Word: w, Count: c})
}

	if a.Count != b.Count {
		return b.Count - a.Count      // убывание по частоте
	}
	return strings.Compare(a.Word, b.Word)  // возрастание по алфавиту
})
```

- Обрезать до `n`, не забыв случай, когда слов меньше десяти

## Частые грабли пятого дня

**Запись в `nil`-мапу.** `var m map[string]int` создаёт `nil`. Паника случится не при объявлении, а при первой записи — возможно, далеко от места ошибки. Мапу-поле в структуре нужно инициализировать явно.

**Расчёт на порядок обхода.** Код, который «работает», а после пятого запуска выдаёт другой результат, — почти всегда это. Нужен порядок — собирайте ключи в срез и сортируйте.

**`len(s)` для длины строки.** Верно только для латиницы. Для кириллицы, эмодзи и любого не-ASCII нужен `utf8.RuneCountInString`.

**Обращение по индексу за символом.** `s[0]` для `"Привет"` вернёт первый **байт** буквы «П», а не саму букву. Нужен символ — идите `range` или конвертируйте в `[]rune`.

**Конкатенация в цикле.** `s += x` создаёт новую строку на каждой итерации — строки неизменяемы. На тысяче итераций это заметно. Правильный инструмент — `strings.Builder`.

**Изменение поля структуры внутри мапы.** `m["k"].Count++` не скомпилируется, если значение мапы — структура. Элемент мапы не адресуем. Варианты: заменить значение целиком или хранить `map[string]*wordCount`.

**`&m[k]` — ошибка компиляции.** По той же причине. У элемента слайса адрес взять можно, у элемента мапы нет: мапа умеет переезжать в памяти при росте.
